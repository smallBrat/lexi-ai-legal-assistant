## Recording tips

- Tools: [Kap](https://getkap.co) (macOS), [ScreenToGif](https://www.screentogif.com/) (Windows), [Peek](https://github.com/phw/peek) (Linux)
- 1440×900 viewport, ~12 fps, 256-color palette
- Target **< 10 MB per GIF** — trim dead time, speed up 1.5× if needed
- Optimize with [gifsicle](https://github.com/kohler/gifsicle): `gifsicle -O3 --lossy=80 -o out.gif in.gif`
